## 💰 Overview

> **FinTrack** is a smart, responsive expense tracker and financial dashboard. Add income & expenses, visualize your spending with charts, filter transactions by month/type, and analyze monthly patterns — all stored locally in your browser. No backend needed.

---

## ✨ Features

- 💵 **Add Transactions** — Log income or expense with title, amount & date
- 📊 **Live Balance** — Total Balance, Income & Expenses update in real-time
- 📋 **Transaction History** — Full list with filter by Month & Type (Income/Expense/All)
- 📈 **Income vs Expense Chart** — Visual bar/pie chart comparison
- 📅 **Monthly Analysis** — Breakdown of spending patterns month by month
- 💾 **LocalStorage** — Data persists even after page refresh
- 🔐 **Login / Signup UI** — Auth modal for user experience
- 📱 **Fully Responsive** — Works on mobile, tablet & desktop

---

## ⚙️ How It Works

```javascript
1. User adds a transaction (income/expense) via the form
2. Balance, income & expense totals update instantly
3. Transaction saved to LocalStorage for persistence
4. Filter by month or type to view specific records
5. Charts render income vs expense comparison visually
6. Monthly analysis section shows spending trends
```
